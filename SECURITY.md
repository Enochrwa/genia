# Security Policy

## Reporting a vulnerability
Do not open a public issue. Email the maintainers (see repository owner profile) with details and steps to reproduce. We aim to acknowledge within 72 hours.

## Scope
Authentication, wallet and ledger, payments and webhooks, game integrity (answer leakage, timer bypass), admin console, data exposure.

## Handling
Reports are triaged by severity; fixes for anything affecting money or personal data are prioritised and disclosed after remediation.

See `docs/07-security` for the full security baseline.

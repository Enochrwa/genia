# Runbook: Incident Response

Severities: SEV1 (money loss/data breach/full outage), SEV2 (major degradation), SEV3 (minor).
Roles: incident lead, communications, scribe.
Steps: declare, stabilise, communicate (status page and support macros), fix, verify, review within 5 working days with action items.
Regulatory/data breach notification timelines follow `docs/08-compliance/privacy-and-data-protection.md`.

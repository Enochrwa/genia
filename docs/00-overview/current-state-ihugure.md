# Current State: IHUGURE APP (ihugure.net)

Source: public site (language picker and Next/Close buttons only visible externally) plus owner screenshots. Backend and data are unknown and must be confirmed.

## Observed flow
Language, entry amount (300, 500, 1000, 2000, 5000), category (Music, Sport, General knowledge), rules, then questions.

## Observed rules (from terms)
- 3 multiple-choice questions, 3 options each, 12 seconds per question
- Stated payout: 200% of the entry amount
- 18+ only; monthly rewards for the most active players
- Operator named in terms; support via Instagram and email only

## Gaps
No wallet or balance model, dense terms, undefined "200%", single language and country, no visible trust layer, unknown server-side integrity, no admin or fraud tooling.

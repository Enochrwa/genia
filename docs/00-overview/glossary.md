# Glossary

| Term | Meaning |
|---|---|
| Entry | Amount a player pays to start a game |
| Game config | Versioned definition of entry, questions, time, prize table, country |
| Hold | Entry funds reserved in the ledger while a game is in progress |
| Settlement | Final ledger posting after a game completes |
| Ledger | Append-only double-entry record of every money movement |
| Idempotency key | Client-supplied key making a request safe to retry |
| Payout reserve | Platform funds that back prizes |
| Minor units | Smallest currency unit as integers (RWF has none) |
| KYC | Know Your Customer identity verification |
| AML | Anti-money-laundering controls |
| Bonus balance | Promotional funds, not withdrawable until rules are met |

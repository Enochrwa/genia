# Fraud and Risk

## Signals

Many accounts per device/IP/phone pattern, abnormal win rates, impossible response times, rapid deposit-withdraw cycles, repeated failed PINs, mismatched KYC names, payment-method reuse across accounts.

## Rules engine

Configurable rules with score and severity -> actions: allow, require review, step-up verification, hold withdrawal, suspend.

## Workflow

Flag -> queue for analyst -> evidence view (games, ledger, devices) -> decision -> audit record -> user notification if action taken.

## Principles

Flag, do not auto-accuse. Provide an appeal path through support.

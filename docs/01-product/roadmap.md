# Roadmap

| Stage | Duration | Outcome |
|---|---|---|
| 0. Discovery and legal | 2-4 weeks | Owner interview, current data access, legal opinion, payment onboarding started, payout model signed off |
| 1. Design | 3-4 weeks | Brand, design system, flows, copy in en/fr/rw |
| 2. Core platform | 8-10 weeks | Auth, wallet/ledger, game engine, question admin, MoMo/Airtel sandbox |
| 3. Hardening | 3-4 weeks | Security review, load tests, fraud rules, reconciliation, responsible-play tools |
| 4. Private beta | 3-4 weeks | Small user group, caps, small real transactions |
| 5. Rwanda launch | ongoing | Public launch and support operations |
| 6. Retention features | 8-12 weeks | Leaderboards, achievements, daily challenge, notifications, analytics |
| 7. Expansion | per market | Legal check, adapters, languages, currency |
| 8. Social and multiplayer | later | Rooms, tournaments, referrals, native apps |

Timeline assumes 2-4 engineers; a solo developer should double it.

## Milestones as epics
E1 Auth and accounts, E2 Ledger and wallet, E3 Payments, E4 Game engine, E5 Question bank, E6 Admin console, E7 Risk and fraud, E8 Player UX, E9 Notifications, E10 Compliance tooling, E11 Observability and DevOps.

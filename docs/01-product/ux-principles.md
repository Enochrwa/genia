# UX Principles

1. Money is never ambiguous: entry, prize, fee, refund rules on the confirm screen.
2. Rules before payment, in 5-6 short lines.
3. Mobile first, tested at 320, 360, 375, 390, 412 px, tablet, desktop; large tap targets.
4. Low-data mode: light pages, caching, offline-tolerant shell.
5. Instant feedback: visible countdown, question counter (1/3), correct answers after play.
6. Connectivity resilience: server decides outcome after a drop.
7. Accessibility: WCAG 2.2 AA, labels, scalable text.
8. Localisation by design: no hard-coded text, RTL-ready, locale-aware numbers and currency.
9. Navigation: Home, Play, Leaderboard, Wallet, History, Profile (bottom bar on mobile).

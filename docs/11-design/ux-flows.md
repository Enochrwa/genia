# UX Flows

## Onboarding

Language -> welcome -> how it works (3 steps) -> phone + OTP -> age confirmation -> home.

## Play

Home -> choose category -> choose entry level -> rules and prize summary -> confirm ("I understand, play") -> question 1..N with countdown -> result (score, prize, correct answers) -> play again / wallet / home.

## Deposit

Wallet -> Deposit -> amount and provider -> confirm -> pending screen with status updates -> receipt.

## Withdraw

Wallet -> Withdraw -> amount and destination -> fee and net shown -> PIN -> status -> receipt.

## Connection loss

Banner "Reconnecting..." -> resume game from server state -> result from server.

## Screens list

Splash, language, onboarding, auth, home, categories, entry selection, rules, game, result, wallet, deposit, withdraw, transactions, receipt, history, game detail, leaderboard, profile, limits, support, help centre, legal pages.

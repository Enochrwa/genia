# Brand and Design System

## Brand
Name: **Genia** (from "genius"). Tagline options: "Answer. Compete. Earn." / "Know more. Win more."
Tone: clear, confident, honest about money. Avoid betting/jackpot language.

## Design tokens (initial)
- Colours: primary deep indigo, accent warm amber, success green, error red, neutral slate; AA contrast verified.
- Typography: Inter (system fallback stack); scale 12/14/16/20/24/32.
- Spacing: 4 px base grid. Radius 12 px cards. Elevation: 2 levels.
- Dark mode supported through CSS variables.

## Core components
Wallet card, game category card, entry selector, rules summary, countdown ring, answer button, progress bar, result summary, transaction row with status chip, toast, modal confirm, bottom navigation.

## Status chips
Pending (amber), Processing (blue), Completed (green), Failed (red).

## Deliverables
Figma library and tokens exported to `packages/ui`.

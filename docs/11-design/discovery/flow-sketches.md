# Flow Sketches for Validation (story G-007)

Low-fidelity text sketches for the five task tests. Draw them on paper or in Figma for the sessions. Copy is shown in English; use Kinyarwanda in sessions.

## Entry and rules (one screen)

```text
Choose your entry          [ 300 ] [ 500 ] [ 1000 ] [ 2000 ] [ 5000 ]
Category                   [ Music ] [ Sport ] [ General knowledge ]

Rules for 500 RWF
 - 3 questions, 3 answers each, 12 seconds per question
 - All 3 correct: you receive 1,000 RWF
 - 2 or fewer correct: you receive 0 RWF   (final wording to be decided, see G-003)
 - Fee: none

[ I understand, play ]
```
